# Positive, Negative & Zero Counter (C Program)

## 📌 Description
This program takes 5 integer inputs from the user and counts how many are positive, negative, and zero.

## 🚀 Working
- User enters 5 numbers
- Program checks each number:
  - Greater than 0 → Positive
  - Less than 0 → Negative
  - Equal to 0 → Zero
- Counts and displays results

## 📥 Input Example

5 -2 0 10 -7


## 📤 Output Example
Positive number = 5
Negative number = -2
Zero number = 0
...
Total positive numbers = 2
Total negative numbers = 2
Total zero numbers = 1


## 🛠️ Concepts Used
- Arrays
- Loops
- Conditional statements
